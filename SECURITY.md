# Security policy

Report vulnerabilities in MCPVetter (the scanner, the local MCP server, or the hosted service) to **security@mcpvetter.com**. We acknowledge within 2 business days and publish fixes in the [changelog](https://github.com/jaablon/mcpvetter/releases).

Please include steps to reproduce. Do not test against other users' accounts or data.

False positives and missed detections in scanner rules are bugs too: open an issue with a redacted config that reproduces it.
